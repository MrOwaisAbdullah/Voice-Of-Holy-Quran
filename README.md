## 🌟 About Voice of Holy Quran

**Voice of Holy Quran** is a dedicated online Quran academy providing personalized Quranic and Islamic education to children and adults worldwide. The platform seamlessly bridges the gap between aspiring students and qualified, certified male and female Quran instructors through structured one-on-one live interactive sessions.

---

## 📚 Core Courses Offered

- **Noorani Qaida**: Foundational Arabic alphabet phonetics and pronunciation for absolute beginners and kids.
- **Quran Reading with Tajweed**: Mastery of proper articulation points (*Makharij*) and Tajweed rules.
- **Quran Memorization (Hifz)**: Personalized Hifz schedules with continuous revision tracking.
- **Tafseer & Quranic Translation**: In-depth understanding and contextual interpretation of the Holy Quran.
- **Islamic Studies for Children**: Fundamental Islamic values, Duas, Salah prayer guides, and Hadith basics.

---

## ✨ Platform Features

- **1-on-1 Personalized Tutoring**: Dedicated attention tailored to each student's pace and learning style.
- **Certified Tutors**: Vetted male and female instructors fluent in English, Urdu, and Arabic.
- **Free Trial Classes**: Prospective students can book free evaluation sessions before enrollment.
- **Flexible Scheduling**: 24/7 time-slot options accommodating time zones in the USA, UK, Canada, Australia, and the Middle East.
- **Responsive & Modern UI**: Fast-loading, accessible, mobile-first design built with modern web technologies.

## 🚀 Getting Started Locally

```bash
# 1. Clone the repository
git clone https://github.com/MrOwaisAbdullah/Voice-Of-Holy-Quran.git

# 2. Navigate to project directory
cd Voice-Of-Holy-Quran

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the application.
