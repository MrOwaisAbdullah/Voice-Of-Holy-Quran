# Voice of Holy Quran — Web Portal & Audio Player

A responsive Islamic web platform and streaming Quran audio player built with Next.js, TypeScript, and Tailwind CSS.

## 📖 Features
- **Surah & Ayah Audio Streaming**: High-quality recitation audio playback with playback controls.
- **Accessible Design**: Clean Arabic typography and responsive navigation across all screen sizes.

## 🛠️ Tech Stack
- **Framework**: Next.js 14 / 15
- **Styling**: Tailwind CSS
- **Language**: TypeScript
